# PF2e Character Gallery Tagger
A small GUI program written in Python to assign tags to token collection for the use with the Foundry Character Gallery


Usage:

1.  Create a new module in Foundry
2.  Go to the module location (.../modules/<your-module>)
3.  In the <your-module> directory create the following directories:
    <your-module>|
    
                 |assets|
    
                        |datasheet
                        |images
 5.  Put all your token images into the <images> directory. Since the tool automatically loads all images in a directory, it is advised to use subdirectories.
 6.  Put the .py-file in the  <your-module> directory
 7.  Run the program
 8.  Move the created datasheet.json in the <datasheet> directory
